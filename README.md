# Telegram-бот для подготовительных курсов

Простой Telegram-бот для онлайн-подготовки абитуриентов (КФУ, филиал в г. Джизак). Бот работает локально через polling и не требует env-конфигурации.

## Возможности
- пробный урок по команде `/start`
- инструкция по оплате (Humo / Uzcard)
- подтверждение оплаты админом через `/confirm <user_id>`
- поэтапная выдача видео и тестов
- уведомление админа после завершения всех этапов

## Быстрый старт
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. В `main.py` укажите токен бота и ваш Telegram user_id:
   - `BOT_TOKEN = "PASTE_BOT_TOKEN_HERE"`
   - `ADMIN_USER_ID = 123456789`
3. Запустите бота:
   ```bash
   python main.py
   ```

## Где хранится контент
Пока контент хранится локально в `sheets.py` (список этапов, видео и тестов). Позже можно заменить на Google Sheets.
